Как пользоваться

Сервис для закупщика сети: найти поставщика, понять условия, запросить коммерческое предложение и вести переговоры в одном месте.

{{ '01'|px }}

Выберите сеть, категорию и город

Список категорий подстраивается под сеть. Город меняет и состав выдачи, и порядок: местные поставщики выше.

{{ '02'|px }}

Сузьте выдачу

«Местные · Возят в город · Все», фильтры «есть цена», «есть контакты», «есть документы», тип компании по ОКВЭД и поиск по названию или товару. Рядом с каждым — сколько подходит.

{{ '03'|px }}

Читайте табло огоньков

Восемь огоньков — цена, мин. заказ, доставка, документы, телефон, email, ИНН, ЕГРЮЛ. Горит — факт найден, у него есть источник. Не горит — спросим в КП.

{{ '04'|px }}

Раскройте поставщика

Слева условия с цитатами и ссылками, документы, юрлицо, контакты. То, чего нет в открытых источниках, отмечено «спросим в КП».

{{ '05'|px }}

Запросите КП

Письмо уже собрано из пробелов карточки — «Открыть в почте» или скопировать. Отметьте статус и оставьте заметку: поставщик попадёт в шортлист.

{{ '06'|px }}

Внесите ответ поставщика

Цена, мин. заказ, доставка, документы из ответа становятся фактами карточки: огонёк загорается, рейтинг пересчитывается, вопрос уходит из письма.

Сравнение и шортлист

Отметьте галочками в выдаче: «В шортлист» добавит сразу нескольких, «Сравнить» покажет 2–4 поставщиков бок о бок.

Выгрузка в Excel

«Скачать XLSX» сохраняет текущую выборку; файл назван по категории, городу и дате. Шортлист выгружается отдельно.

ИИ-ассистент

Те же поиск, карточка и письмо доступны Claude и другим MCP-клиентам по адресу {{ PUBLIC_URL }}/mcp — например: «найди трёх поставщиков моцареллы в Тюмени и подготовь письма».

Откуда данные

{{ '01'|px }}

Кандидаты

Yandex Search API по региону города и рубрики каталога производителей productcenter.ru. Дубли склеиваются по ИНН и домену.

{{ '02'|px }}

Сайты

Главная и до 6 страниц: сначала доставка и оплата, затем опт, контакты, документы — и страница каталога. Меню и футер отбрасываются.

{{ '03'|px }}

Прайс-листы

XLSX, XLS и PDF с сайта: позиции товаров категории с оптовой ценой, из шапки — ИНН и контакты.

{{ '04'|px }}

Факты

Правила, не нейросеть: цена с единицей, мин. заказ числом, признаки доставки, телефоны, email, ИНН с контрольной суммой. У каждого — цитата.

{{ '05'|px }}

Проверка

ИНН → ЕГРЮЛ через DaData: статус, возраст, ОКВЭД. Декларации — открытые данные реестра Росаккредитации.

{{ '06'|px }}

Принципы

Каждый факт — с источником

У условия есть цитата, ссылка на страницу и дата сбора. Чего нет в открытых источниках, сервис не придумывает: это вопрос в письме-запросе КП.

Правила в ядре, ИИ — интерфейс

Извлечение и рейтинг сделаны на правилах: результат воспроизводим и объясним. Ассистент через MCP работает поверх тех же проверенных фактов, а не придумывает их.

Честный сбор

  • robots.txt, паузы между запросами, бот с адресом этой страницы.
  • Капчи и антибот-защиту не обходим.
  • Карты — только через официальные API, частных лиц не собираем.

Ограничения

  • Цену и минимальный заказ публикуют единицы — поэтому запрос КП.
  • Декларации сверяются только у производителей: в открытых данных реестра нет ИНН заявителя.
  • Шортлист и заметки общие для всех посетителей: это демо без авторизации.

Что дальше

  • Передача выбранного поставщика в складской модуль — через тот же MCP.
  • Нейросеть на этапе сбора для условий, написанных свободным текстом, — с проверкой цитаты.
  • Шортлист и статусы через MCP — с авторизацией.
