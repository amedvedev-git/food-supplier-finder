Для кого и зачем

Для менеджера по закупкам сети общепита («Сушкоф и пицца», «Жизньмарт»). Обычно поиск поставщика — это Яндекс, 2ГИС, звонки и Excel: часы на одну категорию. Здесь цикл «найти → собрать условия → сравнить → запросить КП» сжат до минут.

Главный принцип: каждый факт с источником. У цены, минимального заказа, доставки и документов есть цитата, ссылка на страницу и дата сбора. Если в открытых источниках факта нет, сервис так и пишет: «не найдено». Такой пробел становится вопросом в письме-запросе КП.

Те же поиск, карточка с цитатами и письмо КП доступны ИИ-ассистенту (Claude и другим MCP-клиентам) по адресу {{ PUBLIC_URL }}/mcp — только чтение.

Принципы и планы

Почему без нейросети в ядре

Правила воспроизводимы, объяснимы закупщику и не ломаются, если внешняя модель недоступна. Нейросети использовались при разработке. LLM стоит добавлять один раз при сборе и только для свободного текста, где правила не справляются, — с обязательной цитатой-доказательством.

Честный сбор

  • robots.txt, паузы между запросами, User-Agent бота с адресом этой страницы.
  • Капчи и антибот-защиту не обходим: такой источник пропускаем.
  • HTML карт (2ГИС, Яндекс.Карты) не парсим, только официальные API.
  • Частных лиц не собираем, только компании.

Что дальше

  • Реестр деклараций Росаккредитации (открытые данные) по ИНН: реальные номера деклараций.
  • Шортлист и статусы через MCP — с авторизацией.
  • Платный 2GIS API: телефоны и рейтинг точек.
  • Передача выбранного поставщика в складской модуль через тот же MCP.
