# Поиск поставщиков для закупщика сети общепита

Прототип: **https://suppliers.alexmedvedev.com** · тестовое задание Goulash.tech (AI Generalist / AI Automation Specialist).

Закупщик выбирает сеть («Сушкоф и пицца» или «Жизньмарт»), категорию и город. Сервис показывает поставщиков из
открытых источников с рейтингом, ценой, минимальным заказом, доставкой, документами и проверкой юрлица. Отобранных
можно сравнить, добавить в шортлист со статусом и заметкой, отправить им письмо-запрос КП и выгрузить список в XLSX.

## Сценарий

1. **Поиск** — сеть → категория (одно дерево на обе сети, общие категории сравниваются напрямую) → город → фильтры
   с числом подходящих: «работает в моём регионе», «есть цена», «есть контакты», «упоминает документы».
2. **Ведомость** — рейтинг 0–100 и табло из восьми огоньков: какие факты найдены с источником (цена, мин. заказ,
   доставка, документы, телефон, email, ИНН, ЕГРЮЛ), а какие станут вопросами в запросе КП. Условия доставки,
   контакты; карточка раскрывается прямо в строке.
3. **Карточка** — у каждого факта есть цитата, ссылка на страницу-источник и дата сбора. Видно, из чего сложился
   рейтинг и чего не нашлось. Здесь же проверка юрлица по ЕГРЮЛ.
4. **Сравнение** 2–4 поставщиков бок о бок.
5. **Шортлист**: ★, статус (написали / КП получено / договариваемся / отказ), заметки.
6. **Запрос КП** — письмо собирается из пробелов в карточке: нет цены — просим прайс, нет документов — спрашиваем
   декларации и ветсвидетельства. Открывается в почте одной кнопкой.
7. **Живой поиск** — «Найти новых в Яндексе» ищет сайты поставщиков по категории и городу, обходит их и
   проверяет ИНН, около 1–3 минут.

## Что собрано (29.10.2026: Екатеринбург, Тюмень, Челябинск, Уфа)

- **1180 поставщиков по 16 категориям**: 403 найдены через Яндекс в городах сетей (сайты), 783 — производители
  из рубрик productcenter.ru.
- **Заполненность полей** (считаются только разобранные значения: доставка — признаки вроде «по городу» или
  «бесплатно от 5 000 ₽», а не упоминание слова; мин. заказ — число с единицей):

  | Поле | Заполнено |
  |---|---|
  | email | 90% |
  | телефон | 79% |
  | ИНН | 56% |
  | действующее юрлицо по ЕГРЮЛ | 51% |
  | условия доставки | 32% |
  | упоминание документов на сайте | 21% |
  | минимальный заказ | 4% |
  | цена | 3% |
  | ссылка на прайс-лист | 3% |

- **Каждая цитата подтверждает своё значение**: число из цены, мин. заказа и ИНН есть в цитате-источнике у 100%
  фактов (проверка по всей базе после пересборки).
- **Точность топ-10** (ручная проверка автора по четырём категориям: лосось, рис, сыры, упаковка): профильный
  B2B-поставщик в 36 случаях из 40. Ошибки — розничные магазины с доставкой.
- **Вывод.** Контакты и проверка юрлица собираются автоматически почти всегда. Цену и минимальный заказ публикуют
  единицы, поэтому эти пробелы закрывает письмо-запрос КП, а не догадки модели.

## Как работает

```
категория + город
  → запросы и ключевые слова категории (categories.yaml)
  → кандидаты: Yandex Search API (регион города) + рубрики productcenter.ru
  → склейка дублей по ИНН / домену
  → обход сайта: главная + до 4 страниц (контакты, доставка, о компании, документы), ссылки на прайсы;
    сырые ответы кэшируются в data/cache
  → основной контент страницы без меню и футера (trafilatura, алгоритм класса Readability)
  → извлечение фактов правилами (core.extract): со всей страницы — ИНН с контрольной суммой, телефоны, email,
    география; из основного контента — цена за кг/шт, минимальный заказ (число с единицей), условия доставки
    (по городу / области / России, самовывоз, через ТК, бесплатно от N ₽), упоминания документов
  → ЕГРЮЛ через DaData: статус, возраст, ОКВЭД, адрес; юрназвание вместо домена
  → рейтинг (core.score) считается при каждом запросе под выбранные категорию и город;
    цена засчитывается, только если рядом назван товар категории
```

**Рейтинг, 100 баллов.** Ранжирует, насколько поставщик подходит. Баллы даются только за разобранные значения:
упоминание доставки без условий или «минимальный заказ?» без числа не считаются.

| Блок | Баллы | Что даёт баллы |
|---|---|---|
| Релевантность | до 30 | предложение в рубрике каталога; категория на сайте и опт/HoReCa; −20, если похоже на ресторан |
| География | 20 | находится или работает в городе/области; 10 — город только в списке зоны доставки или «доставка по России» |
| Контакты | 10 | телефон, email |
| Условия | 10 | цена товара категории, минимальный заказ, условия доставки |
| Надёжность | до 25 | ИНН, действующее юрлицо, на рынке от 3 лет, ОКВЭД опта или производства; −10 за розницу и −20 за общепит по ОКВЭД |
| Документы | 5 | упоминание деклараций, ветдокументов, ХАССП, ГОСТ на сайте (не проверка по реестру) |

## Почему так

- **Веб-приложение.** Закупщику нужны таблица, сравнение и карточка с источниками. В Telegram-боте это не
  помещается, Streamlit выглядит как админка. Работает по ссылке, ничего не нужно ставить.
- **Ядро без LLM.** Извлечение и рейтинг сделаны на правилах: они воспроизводимы, объяснимы закупщику («почему
  этот первый») и не падают, если внешняя модель недоступна. Нейросети использовались при разработке: анализ
  задания, разведка источников, код, тесты. LLM-проход (YandexGPT) стоит добавлять один раз на этапе сбора и только
  для свободного текста, где правила проседают, с обязательной цитатой-доказательством.
- **Каждый факт — с источником.** «Полнота» без проверяемости ничего не стоит. Пробел честно помечается
  «не найдено» и превращается в вопрос в письме КП.
- **Честный сбор.** robots.txt, паузы, User-Agent бота с адресом страницы «Как это работает». Капчу и
  антибот-защиту не обходим: Пульс цен и agroserver.ru закрыты для ботов, поэтому их пропускаем. HTML карт
  (2ГИС, Яндекс.Карты) не парсим, только API. Частных лиц не собираем.

## Источники

| Источник | Что даёт | Статус |
|---|---|---|
| Yandex Search API | сайты поставщиков по запросу и региону | ✅ платный, ≈0,5 ₽ за запрос |
| productcenter.ru | производители по рубрикам: адрес, email, сайт | ✅ |
| Сайты поставщиков | контакты, ИНН, цена, минимальный заказ, доставка, документы, прайсы | ✅ |
| DaData (ЕГРЮЛ) | статус, возраст, ОКВЭД, адрес по ИНН | ✅ бесплатно до 10 тыс. запросов в день |
| agroserver.ru, Пульс цен | объявления с ценами | ⛔ закрыты для ботов, не обходим |
| 2GIS Catalog API | организации на карте | ⛔ демо-ключ не отдаёт контакты |

## Запуск

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
python test_core.py                                # проверки извлечения и рейтинга
YANDEX_API_KEY=… YANDEX_FOLDER_ID=… DADATA_TOKEN=… python collect.py seed --pages 2   # сбор, нужен российский IP
uvicorn app:app --port 8766
```

Пересборка базы новыми правилами: `SUPPLIERS_DB=data/rebuild.sqlite python collect.py rebuild --pages 2`
(все города сетей, потом каталоги, по очереди), проверить и подменить `data/suppliers.sqlite`. Страницы и
ответы Яндекса и DaData берутся из `data/cache`, поэтому повторный обход и платные запросы не нужны. Свежие данные —
удалить и `data/cache`.

Деплой: `deploy/install.sh`, systemd + Caddy.

| Файл | Что внутри |
|---|---|
| `categories.yaml` | дерево категорий: сети, ключевые слова, запросы, рубрики |
| `core.py` | извлечение фактов, рейтинг, хранилище SQLite |
| `collect.py` | сборщики источников, обход сайтов, DaData |
| `app.py`, `templates/` | интерфейс |
| `test_core.py` | проверки на реальных текстах |

## Ограничения и что дальше

- Цены и минимальный заказ публикует меньшинство поставщиков: остальное закрывает письмо КП.
- PDF- и XLSX-прайсы пока только находятся ссылкой, позиции из них не разбираются.
- Шортлист и заметки общие для всех посетителей: это демо, авторизации нет.
- Дальше: реестр Росаккредитации по ИНН (номера деклараций), разбор прайсов, LLM-проход по свободному тексту,
  платный 2GIS для телефонов точек, передача выбранного поставщика в складской модуль Goulash.
