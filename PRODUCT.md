## Platform

web

## Users

Две аудитории на равных:
- **Закупщик сети общепита** («Сушкоф и пицца», «Жизньмарт»; Екатеринбург, Тюмень, Челябинск, Уфа). Работает за десктопом: ищет 3–5 надёжных поставщиков категории с доставкой в свой город, сравнивает условия, запрашивает КП.
- **Проверяющий от Goulash.tech** (тестовое задание AI Generalist). Открывает прототип по ссылке и за первые секунды должен понять идею, логику и качество.

## Product Purpose

Сжать цикл «найти → собрать условия → сравнить → запросить КП» с часов до минут. Успех — закупщик быстро понимает, с кем связаться и что спросить, и доверяет каждому факту.

## Positioning

Каждый факт с источником: цитата, ссылка на страницу, дата сбора. Пробел честно помечен и превращается в вопрос в письме-запросе КП. Рейтинг прозрачен — видно, из чего сложились баллы. Ядро на правилах, без LLM.

## Operating Context

Сценарий: сеть → категория → город → фильтры (работает в регионе, есть цена, есть контакты, упоминает документы) → таблица с рейтингом → карточка (факты с источниками, «почему такой рейтинг», проверка юрлица по ЕГРЮЛ, статус и заметка, письмо КП) → сравнение 2–4 → шортлист → XLSX. Живой поиск через Яндекс 1–3 минуты.

## Capabilities and Constraints

- Стек: FastAPI + Jinja-шаблоны (`templates/`), SQLite, без сборки фронта. Деплой на Selectel за Caddy.
- 16 категорий, одно дерево на обе сети. Поля: цена (≈4%), мин. заказ (≈7%), условия доставки (признаки: по городу / области / России, самовывоз, через ТК, бесплатно от N ₽), документы (упоминание на сайте, не реестр), телефон, email, ИНН, статус ЕГРЮЛ, ОКВЭД, возраст.
- Цена и мин. заказ публикуются редко — интерфейс не должен выглядеть пустым из-за их отсутствия.
- Шортлист и заметки общие для всех посетителей (демо без авторизации).

## Brand Commitments

Интерфейс выглядит как продукт Goulash.tech (решение пользователя 29.10.2026): их шрифт Onest, графит `#040406`/`#1B1B1B`, белые поверхности, бирюза `#00FFFF` дозированно, пиксельный шрифт (Pixeloid Sans) как акцент, тонкие направляющие сетки, крупные лёгкие цифры. Варианты различаются структурой, не айдентикой.

## Evidence on Hand

Реальная база поставщиков (`data/suppliers.sqlite`, на сервере пересобирается). Нет: отзывов закупщиков, цифр экономии времени, логотипов клиентов — не выдумывать.

## Product Principles

1. Доверие через проверяемость: у факта виден источник, у балла — причина.
2. Пробел — не дыра, а следующий шаг (вопрос в КП).
3. Решение «с кем связаться» — за минуты, без перехода в Excel.
4. Ничего не выдумываем: ни цен, ни отзывов, ни метрик.
